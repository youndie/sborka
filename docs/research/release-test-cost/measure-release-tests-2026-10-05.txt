METHOD   `measure.sh` here. A warm-up invocation links both test binaries once (toolchain, caches,
         compilation). Then N iterations, the arm order alternating (odd: debug then release; even:
         release then debug). An arm is ONE Gradle invocation that reruns exactly two tasks -
         `link<Arm>TestLinuxX64 --rerun` and the test task `--rerun` - with `--no-build-cache`,
         `--no-daemon`. Durations are the task's own start-to-end from the build event API
         (`release-run.init.gradle`, M121_TIMES), not the invocation's wall clock.
         N = 5 hosted, 3 on the Linux box.
NOTE     The "exit N" the harness printed on these runs was the exit code of `date`, not of Gradle
         (`$?` read after a command substitution); the committed measure.sh records Gradle's. The
         outcome below is the task's own result from the event API.

READING
  The release link is 6-13 times the debug link and barely moves with cores: mani 132 s on four,
  106 s on twenty. For mani it is the whole cost, about two minutes per `check`. For kafkakn the
  suite itself is the cost - a broker, eight minutes a run - and the release run doubles the native
  part of `check`.
  kafkakn's release run is RED in every run on both hosts, its debug run green in every run:
  EnqueueTest.a_record_the_queue_has_no_room_for_within_max_block_ms_is_not_queued[linuxX64],
  169 tests, 1 failed, `kotlin.RuntimeException: Unexpected receiver type: kotlin.String` from the
  test's coroutine body - an interface call reaching a value of another type. The stand's first
  draft of the trap, a missing generic cast check and nothing else, failed in release with the same
  message; what kafkakn's cause is was not investigated here.
